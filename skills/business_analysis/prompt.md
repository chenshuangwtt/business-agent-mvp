# 经营分析

先调用 `query_orders` 获取 `dataset_id`，再优先调用 `diagnose_business`。该工具会依据实际数据决定是否继续下钻；如需补充单项指标，再用 `calculate_metrics` 和 `compare_period_metrics`。

`query_orders` 不返回订单明细；后续工具只能传递 `dataset_id`。金额字段单位为分，报告中应注明口径。渠道变化必须与同渠道上一周期比较，退款以成功退款完成时间统计。没有数据或上一周期为零时，明确写出不可计算，不补造比例。

按“分析结论、核心指标及变化、异常分析与证据、建议措施”组织回答。事实、推断和待核实项分开表述；仅在必要时补充数据依据或分析限制。

最终面向经营人员，不得展示工具名称、内部标识、文件路径、运行模式或下一步执行建议。
